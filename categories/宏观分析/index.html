这次加息的性质要说清楚：它不是「经济过热型加息」，而是「通胀顽固型加息」，这个区别决定了后面所有资产的走向。美联储声明里删掉了7月版本中「高通胀部分源于供给冲击、特别是能源」的表述，新增了「国内支出保持韧性」和「今天的政策行动将有助于更及时地实现2%目标」。删掉「供给冲击」这句话是最关键的信号——意味着美联储认为物价压力已经扩散得太广，不能再简单归因于油价了。沃什在发布会上的原话是：「事实很简单，通胀太高，而且已经高了太久」，以及「我们撤走了一剂宽松」。摩根士丹利首席美国经济学家Gapen评论：「这是鹰派的。如果主席认为政策还是宽松的，那说明后面还有活要干。」 香港实行联系汇率制度，港元与美元在7.75-7.85的窄区间内挂钩。根据经济学上的「不可能三角」（一个经济体不可能同时拥有固定汇率、资本自由流动、独立货币政策三者），香港选择了固定汇率+资本自由流动，代价就是放弃独立货币政策。所以美联储加息，香港就必须跟——这不是金管局的主动选择，而是预设公式自动触发的机械结果。 金管局总裁余伟文当天的表态很坦诚，三个要点：① 「港美息差进一步扩阔，套息交易有机会令港元逐步转弱」——承认资金会流向美元；② 「港汇和拆息走向存在较多的变数」——不给出前瞻指引；③ 提醒市民「在作出置业、投资或借贷决定时，需充分考虑及管理利率风险」。 一个必须纠正的网络传闻：本次事件后网络上流传「恒指在加息公告后两小时内下挫2.3%、科技股板块领跌4.1%」、「HIBOR隔夜利率已突破4.1%」等说法。经核对真实市场数据，这些数字均不准确：恒指9月17日实际跌幅为-1.05%（收24454.42），恒生科技指数跌-1.25%（非4.1%）；HIBOR隔夜利率实际为2.12%、1个月为2.95%（非4.1%）。请以香港银行公会与交易所的官方数据为准，勿被夸大数字误导判断。 二、恒生指数走势（近40个交易日） 从K线看，恒指的调整早在加息落地之前就开始了，这一点很重要。9月以来恒指的路径：9/1收25211 → 9/4冲高至25443（本阶段高点）→ 9/8跌破25000 → 9/10收24686 → 9/11收24523 → 9/14反弹收24917 → 9/15回落收24667 → 9/16收24713 → 9/17加息落地跌至24454.42（-1.05%）。 关键观察：市场其实已经提前消化了大部分预期。加息前市场对25bp的定价已接近九成（CME数据），所以真正的「预期差」不在加息本身，而在点阵图的鹰派程度——16名官员预计年内还要加、通胀回到2%推迟到2029年，这两点才是9月17日下跌的主因。 阶段跌幅对比（这组数据说明调整的性质）：恒指近5日-2.00%、近10日-3.01%、近20日-4.84%，但近60日仍+4.45%、年初至今-4.59%。即近一个月在调整，但中期（60日）仍是正收益。恒生科技指数的分化更明显：近20日-9.13%、年初至今-22.56%，科技股的调整远深于大盘——这正是「高估值资产对利率最敏感」的直接体现，也是本次加息影响的核心逻辑（详见第五章）。 这是本次事件中最反直觉、也最值得说清楚的一件事：美联储加息、美元指数升破100，但人民币不但没跌，反而升到了2023年2月以来的最高位。9月17日人民币对美元中间价调升48个基点至6.7580，连续第7个交易日调升；在岸人民币报6.7116，离岸人民币报6.7094逆势微升0.03%。对比同日其他非美货币的表现：欧元跌0.67%、英镑跌0.72%、澳元跌0.62%、日元跌0.77%、瑞郎跌0.87%——非美货币普遍下跌，人民币是少数逆势走强的货币。 传导链条：教科书逻辑 vs 现实 教科书上的标准传导（本次并未生效）： 美联储加息 → 美元资产收益率上升 → 中美利差扩大（倒挂加深）→ 资本流向美元 → 人民币贬值压力 现实中发生的（三股力量顶住了贬值压力）： ① 强出口 + 高贸易顺差 + 企业结汇需求 → 实盘外汇供给充足 → 支撑人民币 ② 央行「以我为主」+ 中间价逆周期调节 → 连续7日上调中间价释放稳汇率信号 ③ 全球去美元化 + 人民币国际化推进 → 结构性配置需求上升 为什么人民币能扛住？四个层面拆解： ① 最根本的原因：贸易顺差提供了实盘美元供给。汇率短期看利差，中长期看国际收支。中国维持着庞大的贸易顺差，出口企业赚到美元后需要结汇（把美元换成人民币用于国内经营），这构成了持续的、真实的人民币买盘。这种实盘需求不受利差影响——出口商不会因为美元利率高2个点就不结汇了，因为他们需要人民币付工资、付货款。这是与2015-2016年那轮贬值压力最大的不同。 ② 央行的态度：明确的「以我为主」。连续7个交易日调升中间价，是非常清晰的信号——中间价是央行可以直接调控的，它代表官方对合理汇率水平的指引。央行二季度货币政策执行报告的表述是「保持人民币汇率在合理均衡水平上的基本稳定，防范汇率超调风险」。当前6.75的水平配合连续上调，说明央行既不希望过快升值损害出口，也不允许因外部加息而无序贬值。 ③ 一个需要澄清的常见误解：人民币升值 ≠ 国内降息空间打开。市场上有观点认为「人民币升值给降息腾出了空间」，但央行从未把汇率升值当作降息的触发条件。真正制约国内降息的是三块硬约束：一是银行净息差已降至1.41%~1.42%的历史低位（17个季度最低附近），再降息就是挤压银行盈利能力；二是中美利差深度倒挂（超300个基点），本次美联储加息使倒挂进一步加深，压缩国内降息空间；三是PPI转正、核心CPI回升，「防通缩」的紧迫性下降。8月CPI同比+0.8%、PPI同比+3.8%，均较前值回升。 ④ 本次加息对国内货币政策的实际影响：降准的优先级高于降息。这是当前机构的主流判断。逻辑是：降准释放的是长期低成本资金，能在不直接压缩银行息差、不直接冲击利差的前提下支持实体经济，而且能为后续LPR下调做前置铺垫。机构预计存款准备金率年内或有25-50个基点的下降空间。而LPR已连续15个月维持在1年期3.00%、5年期以上3.50%不变，下半年下降空间预计仅5-10个基点。本次美联储加息落地后，「中美货币政策背向而行」的格局更加确立——美国加息、中国仍需宽松，这会加大资本流动和汇率波动，但不改变国内政策的自主性。 对不同人群的实际影响 人群/场景影响方向具体说明 出国留学/旅游换汇有利人民币走强，换美元更便宜（6.7580 vs 年初更高水平） 出口企业不利人民币升值削弱价格竞争力，压缩汇兑收益 进口企业/原材料采购有利购买同等美元计价商品所需人民币减少 持有美元资产者双向美元利息收益上升，但换回人民币时汇兑损失 国内房贷持有者中性偏有利LPR维持3.50%不变，降准预期仍存，月供不受美联储直接影响 QDII/海外基金投资者不利人民币升值时，海外资产折算回人民币收益被摊薄 人民币的风险提示：不要把「当前偏强」误读为「无脑看多」。三个需要跟踪的变量：① 如果美联储真的在10月或12月再加一次息，中美利差倒挂将进一步加深至更极端水平，届时套利资金外流压力会累积；② 如果国内降准降息落地（机构预计窗口在9月下旬至10月中下旬），短期会对人民币形成反向压力；③ 贸易顺差的可持续性——如果美国关税政策进一步升级冲击出口，实盘美元供给会减少，这是人民币当前最重要支撑的潜在裂缝。综合判断：短期人民币在6.70-6.80区间双向波动的概率最大，单边大幅贬值的条件并不具备，但也不宜期待持续快速升值。 四、对黄金的影响：短期承压，长期逻辑未坏 COMEX黄金4322.2 美元/盎司 当日变动-65.3 (-1.49%) 国内黄金9999925.91 元/克 国内当日变动-10.84 (-1.16%) 传导链条：为什么加息压制黄金 核心机制（黄金的定价本质）： 美联储加息 → 美债名义收益率上升（10年期突破5%）→ 实际利率（名义利率−通胀预期）上升 → 持有黄金的机会成本上升 → 黄金吸引力下降 叠加第二条路径： 加息 → 美元指数走强（升破100）→ 黄金以美元计价 → 美元贵了，同样的黄金需要更少美元 → 金价承压 关键理解：黄金不生息。持有黄金没有利息，持有美债有5%的利息。 当无风险利率越高，「拿着不生息的黄金」的代价就越大——这就是黄金怕加息的根本原因。 短期的负面冲击是真实的，但要看清三个层次： ① 跌幅其实相当克制，这是最值得注意的地方。COMEX黄金-1.49%至4322.2美元，国内黄金9999-1.16%至925.91元/克。对比历史上加息周期中黄金的单日反应，在「三年多来首次加息+点阵图暗示还要加+美元升破100+10年美债破5%」这样一套鹰派组合拳之下，黄金只跌了1.5%左右，实际上表现出了相当强的韧性。发布会期间现货黄金一度跌超1%、白银跌超2%，但并未出现崩塌式下跌。 ② 位置视角：黄金仍处于历史高位区域。COMEX黄金4322.2美元，52周区间是3660.5 — 5626.8美元。国内黄金9999报925.91元/克，52周区间756.4 — 1256元。即当前价格距52周低点仍高出约18%（COMEX）和22%（国内）。这说明黄金在此前已经消化了很多，本次加息带来的是高位回调而非趋势反转。 ③ 长期逻辑为什么没坏——这是本章最核心的判断。本次加息的原因是「通胀太高且持续太久」，而不是经济过热。美联储自己的预测里，通胀回到2%目标的时点从2028年推迟到了2029年，2026年PCE预测上调至3.7%、核心PCE上调至3.4%。这意味着未来三年美国仍将处于「通胀显著高于目标」的环境中——而这恰恰是黄金作为抗通胀资产的长期支撑。 一个关键但被忽视的事实：香港的「利率脱钩」现象 这是本文最重要、也最容易被误读的一点：香港虽然政策利率跟随美国升到4.25%，但真实的市场利率（HIBOR）远低于美国，且本次加息后HIBOR几乎没动。请看这组数据对比——美国联邦基金利率3.75%-4.00%、香港基本利率4.25%，但香港银行间实际拆借利率：隔夜HIBOR仅2.12%、1个月HIBOR仅2.95%、3个月3.12%、6个月3.35%、12个月3.75%。1个月HIBOR（2.95%）比美国政策利率下限（3.75%）低了整整80个基点。 为什么会脱钩？这个现象对你的实际影响是什么？ 脱钩的原因：香港银行体系港元资金相对充裕。基本利率是金管局贴现窗的「惩罚性」利率——它是银行在流动性紧张时向金管局借钱的成本，属于利率走廊的上限，而非市场实际成交利率。而HIBOR是银行之间真实的拆借成交价。当银行体系资金充裕时，银行之间互相拆借就能满足需求，根本不需要去用4.25%的贴现窗，所以HIBOR可以长期低于基本利率。 对房贷族的实际影响（这是最实用的部分）：香港按揭主流是H按（挂钩HIBOR）和P按（挂钩最优惠利率）。H按挂钩的是1个月HIBOR（当前2.95%），而不是4.25%的基本利率。而9月17日金管局加息后，1个月HIBOR报2.55476%（etnet口径）至2.95%（香港银行公会口径）区间，当日无升跌。换句话说：政策利率升了25个基点，但决定你月供的HIBOR当天基本没动。 P按（最优惠利率）方面：余伟文明确表示「银行会综合考虑同业市场资金供求、拆息及现时相关利率水平、本身的资金成本结构等因素，评估是否需要调整及调整的幅度」——即最优惠利率是否上调，由各家银行自主决定，不是自动跟随的。在HIBOR远低于基本利率、银行资金成本压力不大的情况下，银行立即上调P的动力有限。 所以对「按揭族要哭了」这类说法需要冷静看待：真正需要担心的场景是「HIBOR开始快速向基本利率靠拢」——那意味着港元资金真的开始外流、银行体系结余下降。这才是真正值得盯的指标，而不是政策利率的数字本身。当前1个月HIBOR为2.95%，距基本利率4.25%还有130个基点的缓冲空间。 港汇与套息交易：需要跟踪的核心指标 指标当前值意义警戒信号
