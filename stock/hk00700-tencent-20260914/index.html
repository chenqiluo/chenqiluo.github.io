今天最有价值的信息不在涨了多少，而在于「三高抬升 + 逆势独涨 + 地量」这三件事同时成立。先把日内过程还原：昨收428.40，今天低开423.8（低开1.07%），而423.8同时就是全天最低价——和上一交易日一样，又是「开盘即最低」的光脚形态；此后一路推到435.4，最终收430.60，收在全天最高价下方1.10%的位置，并且重新站回430整数关口（9/10失守）之上。
这根K线要读出四层信息。

第一层：三个价格全部环比抬高，短期结构第一次出现改善。最低价 419.4 → 423.8（抬高4.4港元）、最高价 430.8 → 435.4（抬高4.6港元）、收盘价 428.4 → 430.6（抬高2.2港元）。连续两个交易日都是「低开高走的光脚阳线」，且第二根的三个关键价位全部高于第一根，这在技术上构成最初级但最真实的「底部抬升」结构。此前9月的走势是清一色「低点不断创新低」，今天是第一次把这个链条打断。

第二层：腾讯是今天中概互联网里唯一上涨的。同一天阿里巴巴-1.58%、快手-2.24%、美团-0.20%、网易-0.05%，只有腾讯+0.51%。这一点比涨幅本身重要得多——上一交易日是四家集体反弹（腾讯只是涨得最多），今天是板块整体走弱、腾讯单独走强，说明买盘不是被行情裹着走的被动流入，而是有人专门在买腾讯。资金面数据也吻合：主力净流入1.73亿、南向净买入61.33万股。

第三层：也是最需要泼冷水的一层——量能萎缩到了地量。成交847.2万股、36.45亿港元，只有上一交易日（1562.8万股/66.75亿）的55%，是9/10（2233.3万股/95.33亿）的38%；换手率0.09%、量比0.65，都是近月最低读数。三天量能路径是 95.33亿 → 66.75亿 → 36.45亿，连续两天腰斩。这说明今天的上涨依然是「没人卖」而不是「有人抢」——抛压枯竭型反弹的第二天。好的一面是「地量往往对应地价」，市场分歧已经收敛到极致；坏的一面是这种反弹缺乏成交量背书，一旦有稍大的卖单出现就容易被打回去。

第四层：收盘价站在均价之上，且几乎贴住MA5。今日均价430.283，收盘430.60高于均价0.32港元，尾盘没有获利抛压。更关键的是MA5已经下移到430.80，收盘价距MA5只差0.05%——上一交易日这个差距还是0.88%。五日均线已经近在眼前，明天只要不跌，MA5就会被自然收复。

位置：430.60距52周高点677.70回撤36.46%，距52周低点411高出4.77%，年初至今仍跌27.47%。腾讯依然处在估值与股价的多年低位区间。
二、K线走势（近39个交易日）
中期结构回顾：7月中至今依次走完「双顶 → 破位 → 箱体 → 箱体失守 → 加速赶底 → 止跌 → 低点抬升」七个阶段。7/16冲高494.8形成第一头部，7/22一根跳空长阴从468直砸440.6；7月底至8月初修复到490~497（8/3~8/5）构筑第二头部，形成教科书式M形双顶；8/12~8/13再度破位，8/13放天量砸到441，锁定438~462箱体；9月箱体失守后连续下台阶，9/11盘中最低419.4完成赶底。

今日形态判读（四个确认信号 + 一个警告）：
① 低点抬升成立——419.4 → 423.8，且今天的最低点就是开盘价，意味着开盘之后再没有卖方能把价格压回昨天的低位；
② 430整数关口收复——9/10跌穿430后连续三日在其下方运行，今天首次收在430之上，430从「压力」暂时转回「支撑」；
③ 股价贴住MA5（430.80），差距仅0.05%，五日线压制实质上已经解除；
④ KDJ形成金叉——K值24.56已上穿D值19.49（上一交易日K17.22尚在D之下），这是9月以来第一次出现日线KDJ金叉；
⑤ 警告：量能是三天内的第三次萎缩，36.45亿只有9/10的38%。地量意味着分歧收敛，但也意味着目前没有任何一方有能力主导方向，属于典型的「等待变盘」状态。

关键位置（今日更新）：上方压力依次为430.80（MA5，已贴身）、434.78（MA10）、435.17（BBI）、435.40（今日最高）、441.16（SAR）、441.46（MA20/布林中轨）、450.85（MA60）；下方支撑依次为430（整数关口）、424.26（布林下轨）、423.80（今日最低，第一防线）、419.40（9/11最低，第二防线）、411（52周低点，生死线）、395.65（ENE通道下轨）。

结论直白讲：现在的位置是「底部抬升初现，但量能不给答案」。真正的确认信号有两个——放量站上435~441区间（MA10/BBI/SAR三线密集区）视为短期止跌成立；有效突破441.46（MA20/布林中轨）才算反弹结构确立。反过来，如果放量跌破423.8，419.4会被快速回测；跌破419.4则411生死线难免。

腾讯的情况是反过来的：它的主业赚的钱（经营利润1,550.3亿）比报表上写的净利润（1,313.9亿）还要多。为什么？因为主业赚的1,550.3亿要先交302.7亿的税、分37.5亿给少数股东，剩下的才是归母净利。也就是说腾讯不但没有靠非经营项目撑利润，反而是主业赚的钱被税和少数股东分走了一部分之后，才是我们看到的报表数字。

非经营性收益只占税前利润的6.3%。这103.7亿里包含利息收入、联营公司损益、公允价值变动等，即使明年这部分全部归零，对腾讯利润的冲击也不到7%。对比第十一章方法论里提到的极端案例（某GPU公司非经营收益占利润总额105.75%，即账面盈利全靠水分），腾讯处在完全相反的一端。

国内政策层面已基本不构成风险来源。回顾2021~2022年，腾讯股价从700+跌到200以下的核心驱动是政策不确定性（游戏版号暂停、反垄断、教育/游戏行业整治）。到2026年，这些因素已系统性解除：版号常态化发放、平台经济定调为「支持健康发展」、AI被列为国家战略方向。所以今天腾讯14.46倍PE的低估值，其成因已经不是政策风险，而是市场对AI资本开支和增长天花板的担忧——这是一个非常重要的性质区别。政策风险是不可预测、不可估值的；而资本开支担忧是可以被财报逐季验证或推翻的（本报告基本面章节已用现金流数据部分推翻）。

真正的政策风险已外移到中美科技博弈。高端AI芯片管制直接约束腾讯的算力扩张速度。腾讯的应对策略是双轨——一方面投资长鑫存储、燧原科技等国产供应链，一方面把AI重心放在推理侧和应用侧（微信AI社交、WorkBuddy办公提效）而非训练侧，降低对最高端算力的依赖度。今日富瑞报告提到的「DeepSeek-V4.1-Flash性价比突出」正好从另一个角度支撑这个策略——如果开源模型的推理成本持续下降，腾讯对高端算力的依赖会进一步减弱，芯片管制的边际影响也会随之下降。
