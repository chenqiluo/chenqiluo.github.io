解读：昨天的报告里写了一句话——「433这个位置已经守不住了，接下来真正要看的是430」。今天这句话应验了，而且比预想的更干脆。

第一，430不是被慢慢磨破的，是被一次性跳过去的。今天开盘430.0，最高430.8，也就是说全天最高价就在430附近，开盘即是全天最高点，此后一路阴跌，最低425.0，收426.20。这是典型的光头阴线：没有任何一次像样的反抽，说明430这个位置上方的抛压是连续的、有计划的，不是恐慌性抛售。

第二，是放量破位而不是缩量阴跌。成交量1735.8万股、成交额74.13亿港元，比昨日（1343.7万股/58.42亿）继续放大29%，量比1.31升到近期高位。连续两天「跌一点、量放一点」，说明这一轮下跌有真实资金在离场，不能简单当作无量阴跌看待。

第三，也是今天最容易被忽略的一点：这不是腾讯一个人的事。同日阿里巴巴跌2.91%、美团跌3.79%、网易跌0.49%，整个中概互联网板块集体走弱，腾讯1.80%的跌幅在四家里排倒数第二小。这说明今天的下跌主因是板块系统性调整（港股流动性+对AI资本开支的集体担忧），而不是腾讯自身基本面出了问题。这个区别很重要——系统性下跌通常跌得快、修复也快，个股基本面恶化则是长期的。

第四，位置。426.20距离52周低点411港元只剩3.57%，距离52周高点677.70港元已回撤37.1%，年初至今跌28.21%。换句话说，腾讯已经把2026年全年的涨幅连本带利吐完，还倒欠近三成。
二、K线走势（近38个交易日）
中期结构：7月中至今是一段完整的「双顶—破位—箱体—箱体失守—加速赶底」路径。7/16冲高494.8形成第一个头部，7/22一根跳空长阴从468直砸440.6；7月底至8月初修复到490~497（8/3~8/5）构筑第二个头部，形成教科书式的M形双顶；8/12~8/13再度破位，8/13放出6642万股天量砸到441，就此锁定438~462的震荡箱体。

9月以来的节奏（连续下台阶）：9/1收441.4 → 9/2收438.2 → 9/3光头光脚433 → 9/4放量反抽442.8（成交106.65亿）→ 9/7回落438.4 → 9/8地量435.4 → 9/9跌破前低433.0 → 今日9/10放量跌穿430，收426.20，最低425.0。九个交易日里只有一根像样的阳线，且那根阳线的成果已被完全吞没。

今日形态判读（三个确认信号）：
① 箱体下沿438已彻底失守，且失守后没有出现任何回抽确认，直接下了一个台阶；
② 收盘价426.20低于布林带下轨427.68——股价跑到了布林通道外面，这在统计上属于「两倍标准差之外」的极端位置，历史上通常对应两种结局：要么是加速赶底的最后一段，要么是趋势加速的开始；
③ 9/4那根放量阳线（442.8）的全部涨幅已被回吐，且今天收盘比9/4的最低价440还低13.8港元，说明9/4那批在442附近进场的资金已全部套牢。

关键位置（今日更新）：上方压力依次为430（今日开盘价，已转为压力）、435.40（MA5）、439.78（MA10）、442.87（MA20/布林中轨）、451.30（MA60）；下方支撑依次为425.0（今日最低）、420（心理关口）、411（52周低点，最后防线）、400.20（ENE通道下轨）。

结论直白讲：430破了以后，中间到411几乎是真空地带，只有420一个心理关口能稍作缓冲。411是这轮调整的生死线——守住则「双底」成立，可以看一波像样的反弹；放量跌破，下一个参考位就要看400整数关和ENE下轨400.2了。

红线（压力序列）：2026年以来每一次反弹的高点都比上一次更低——521.2 → 494.8 → 497.8 → 462.2 → 447.6 → 442.6 → 430.8（今日）。七个高点无一例外逐级下移，下降通道的斜率非常稳定，中期下跌趋势至今没有出现任何被打破的迹象。今天的430.8成为这个序列里的最新一个、也是最低的一个高点。

绿线（支撑序列）：8月以来的低点是 439.6 → 438.0 → 433.0 → 435.0 → 432.8 → 425.0（今日）。昨天报告提到432.8打破了原本的「跌幅收敛」结构，今天425.0进一步向下延伸，且这一次的跌幅（7.8港元）明显大于此前几次（1~3港元）。支撑线不但没有走平，反而在加速下行——这是赶底阶段的典型特征，而不是筑底阶段。

结论：趋势已经从前期的「缓慢阴跌」切换为「加速下探」。确认反转的唯一有效信号仍然是股价放量突破462港元、打破红线持续下移的格局——目前距离该位置有8.4%，短期内不具备可能性。在此之前所有反弹都只能视为下降通道内的技术性修复，不宜追高。但反过来说，加速下探往往也意味着离阶段性底部更近，而不是更远。
时空量化图（合成震荡器 · 危机线85 / 中间线50 / 安全线15）
合成震荡器由 0.40×RSI(6) + 0.30×KDJ_K + 0.30×(100−WR6) 加权后经EMA(21)平滑得到，用来衡量股价在「时间×空间」维度上的超买超卖程度。今日各分项已全面进入极端区：RSI(6)=27.42（低于30为超卖）、KDJ_K=10.37、WR(6)=93.81（高于80为超卖，数值越高越超卖）。三个分项同时触及极值，合成指标已经贴近甚至跌破安全线15。

更极端的两个读数是：KDJ的J值已跌到−3.34（负数），以及CCI(14)=−181.58（低于−100即为超卖，−180以下属于罕见极值）。这两个指标出现这种数值，在腾讯过去两年里屈指可数。

怎么用这张图：超卖不等于见底，它只说明「短期跌得太快、跌幅透支」，在强下跌趋势里超卖可以持续钝化很久。它的正确用法是——不要在这个位置恐慌割肉（此时卖出往往卖在最差的价格），同时也不要因为超卖就重仓抄底（需要等价格本身给出止跌信号）。真正可以加仓的确认信号是：出现一根放量长下影阳线，且合成指标从底部拐头向上穿越安全线。目前尚未出现。

技术面矛盾点（必须讲清楚）：今天的技术面同时给出了两组方向相反的信号。看空的是趋势类指标——均线完全空头排列、MACD绿柱放大、SAR高悬、股价跌破布林下轨且创调整新低，这些说明下跌趋势没有结束。看多的是摆动类指标——KDJ的J值为负、CCI跌破-180、RSI6跌破30、WR超过93，这些说明短期跌幅已经透支。

两组信号并存时的标准处理方式是：趋势指标决定方向，摆动指标决定节奏。也就是——方向上仍以谨慎为主、不做趋势反转的假设；但节奏上不宜在此刻杀跌，反而应该开始分批布局。唯一需要警惕的是BIAS乖离率还没到极端值（-4.47% vs 历史极值-10%），这提示如果出现最后一跌，空间可能到405~410一带。

这个筹码结构意味着什么？分两面看。

负面的一面：上方436~455区间堆积了三个月的密集套牢盘。一旦股价反弹到这个区域，会持续遭遇解套盘的抛压。这就是为什么MA20（442.87）和MA60（451.30）不只是均线，更是实实在在的筹码密集区——反弹到443一带大概率会遇到第一波像样的阻力，到452一带阻力会更大。

正面的一面：当所有近期买盘都被套住时，愿意在此刻继续割肉的人反而变少了。这就是筹码分析里说的「浮筹清洗完毕」。今天散户净流出2.49亿、主力净流出收窄，某种程度上正是这个逻辑的体现。同时注意到，南向资金的季度增持成本大约在500港元/股（93.33亿÷1862万股≈501港元），它们浮亏近15%却仍在今天继续加仓——这说明这批长线资金的持仓成本容忍度远高于市场平均水平。

操作含义：现价426.20低于所有周期的平均成本，属于「筹码真空下沿」。往下到411之间几乎没有成交密集区，所以一旦跌破425会跌得比较快（缺乏支撑）；但同样地，一旦企稳反弹，430~435这一段也会走得比较顺（缺乏套牢盘），真正的考验在443。

基本面本身没有任何问题，甚至可以说相当优秀。三个数字最能说明质量：

① 经营利润增速（+20.15%）明显快于营收增速（+15.57%）。这中间4.6个百分点的差额就是经营杠杆——收入涨得快、成本涨得慢，利润被放大。毛利率57.25%、同比提升（毛利增速+17.36% > 营收增速+15.57%），说明高毛利业务（广告、游戏、金融科技）占比在提升，而不是靠打价格战换收入。

② 三块主营业务全部健康。游戏基本盘稳固（8月全球移动游戏Top20中腾讯系产品收入集中爆发）；广告业务受益于视频号流量变现和AI投放提效，是当前增速最快的板块；金融科技及企业服务近30%的占比，是云和AI能力的商业化出口。三条腿走路，没有单一依赖。

③ 财务健康度极佳。资产负债率43.39%，流动比率1.287，账上现金2382.48亿港元，净资产1.31万亿港元。ROE（半年）10.16%，年化约20%，对于一家3.88万亿市值的巨头来说是很高的资本回报率。

那问题出在哪？为什么股价还在跌？核心在下面这张表要讲的资本开支——市场担心的不是腾讯赚不赚钱，而是赚到的钱要拿去投AI，导致自由现金流被压缩、分红回购的空间变小。这也是9月9日湘财证券那份研报的核心观点：腾讯正从「利润释放期」进入「AI再投资期」。

第一步·看表面结果：归母净利1313.86亿港元，同比+15.82%，实实在在的增长，不是扭亏也不是靠水分。

第二步·拆非经营性收益：税前利润总额1654.01亿，其中经营利润1550.30亿，差额103.71亿来自联营合营企业损益、投资收益等非经营项目，占利润总额仅6.27%。对照盈利质量判断标准（>50%即失真、>100%为主业实亏），腾讯的6.27%意味着报表利润几乎完全由主业创造。这一点尤其难得——腾讯持有大量上市公司股权（京东、美团、拼多多、Sea等），完全有条件靠公允价值变动美化报表，但它没有这么做。

第三步·看扣非后的主业：剔除那103.71亿非经营收益后，主业对应的税前利润仍有1550.30亿，同比+20.15%，增速比报表净利增速（+15.82%）还要高。这是一个非常关键的反向信号——通常公司是靠非经营收益把利润增速做高，腾讯反而是主业增速高于报表增速，说明非经营部分是在拖后腿，主业比报表看起来更好。

第四步·看边际改善：毛利率57.25%、毛利增速17.36%高于营收增速15.57%，经营杠杆持续释放，无恶化迹象。

第五步·现金流交叉验证（最硬的一条）：经营活动现金流净额1773.77亿港元，是归母净利1313.86亿的1.35倍。这意味着每赚1块钱的账面利润，实际收回了1.35块的真金白银。纸面利润完全有现金支撑，甚至超额支撑。期末现金2382.48亿港元。
唯一需要盯住的变量：资本开支。2026年上半年购建固定资产等支出1100.86亿港元，相当于经营现金流（1773.77亿）的62%。也就是说，扣掉AI基建投入后，上半年真正的自由现金流约为672.91亿港元，而同期分红及利息支付就用掉了571.82亿。

这正是当前市场分歧的核心，也是股价从677跌到426的根本原因——不是盈利变差，而是「赚到的钱去哪了」变了。过去腾讯是把利润拿来回购+分红（利润释放期），现在要把大头投进AI算力（再投资期）。短期看，这压缩了股东回报；长期看，如果AI投入能转化为广告提效和云收入，回报会更大。

这个不确定性会持续压制估值，直到市场看到AI投入的明确产出证据。盈利质量维度扣0.5分（由10分记为9.0分），扣的就是这一点。

这张表要读出三层意思。

第一层：今天的下跌是板块性的，不是腾讯的错。四家全部下跌，美团-3.79%、阿里-2.91%都比腾讯跌得更狠。这种同步性说明驱动因素是共同的——港股流动性偏紧、市场对中概互联网集体投入AI资本开支的回报周期存疑。个股基本面在这种日子里几乎不起作用。系统性下跌的修复通常也是系统性的，需要等待板块层面的催化（如美联储降息落地、AI变现数据兑现），而不是等腾讯自己出利好。

第二层：换标尺会翻转，别只看一个数。按PE算腾讯14.31倍全场最便宜；但按PB算腾讯2.98倍反而是第二贵的（阿里只有1.65倍）。这个差异的本质是：腾讯的资产回报率（ROE年化约20%）远高于阿里，所以市场愿意给它更高的PB。用PE看便宜、用PB看不便宜，两者都对——买腾讯买的是高质量的盈利能力，不是便宜的账面资产。想买「账面便宜」的应该看阿里，想买「盈利便宜」的才看腾讯。

第三层：近20日腾讯是四家里最抗跌的（-3.36%）。阿里同期跌12.55%、美团跌17.97%，腾讯只跌3.36%。这说明在板块整体下行中，资金把腾讯当成了防御性品种——因为它盈利确定、现金流强、还在天天回购。这种相对强度是一个正面信号：当板块见底反弹时，最抗跌的品种通常不是弹性最大的，但一定是最先企稳的。

收敛到腾讯自己：在四家里，腾讯是唯一同时具备「PE最低 + 主业真实盈利 + 近20日最抗跌 + 持续回购 + 南向持续增持」五个条件的标的。它的问题不是质地，而是AI资本开支带来的短期股东回报压缩——这个问题阿里和美团只会更严重（美团还在亏损）。因此在中概互联网这个赛道里，如果一定要配置，腾讯依然是确定性最高的第一选择。

口径提示：四家均为港股HKFRS口径，可比性较好；腾讯财务数据为港元口径中期报告，美团PE为负系因当前处于亏损状态、不具备PE比较意义；阿里PE(TTM)受其一次性损益影响较大，横向比较时需注意。
