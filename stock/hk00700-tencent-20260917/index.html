另一个信号是全天最高价431.00出现在开盘后不久，收盘426.00几乎贴着全天最低425.00——典型的"低开低走、尾盘弱势收在低位"，属于当日多头完全交出主动权的形态。
二、K线走势（近40个交易日）
中期结构回顾（7月中至今，十个阶段）：「双顶 → 破位 → 箱体 → 箱体失守 → 加速赶底 → 止跌 → 低点抬升 → 量增价升 → 缩量歇脚 → 反弹作废」。

7/16冲高494.8形成第一头部；7/22一根跳空长阴从468直砸440.6；7月底至8月初修复到490~497（8/3~8/5）构筑第二头部，形成教科书式M形双顶；8/12~8/13再度破位，8/13放量砸到441，此后锁定438~462箱体运行两周；9月箱体失守后连续下台阶，9/10收425.6、9/11盘中最低419.4完成赶底；9/11~9/15连续三根低开高走阳线，9/15放量冲高446（当日主力净流入12.6亿）看似确认反转；但9/16缩量光头阴线率先示警，今日9/17在美联储加息利空下跳空低开、收426.00，把9/11以来三根阳线的全部涨幅吞掉，这波反弹正式宣告失败。

关键量价背离：9/15放量突破（95.78亿）→ 9/16缩量回落（55.17亿）→ 9/17继续缩量下跌（53.47亿）。上涨要量、下跌缩量本是好事，但此处的缩量下跌发生在反弹结构被破坏的位置，性质是"买盘直接消失"而非"卖盘枯竭"，不构成止跌信号。

⚠️ 但资金面有三点隐忧，这也是资金面只给5.5分的原因：

1）成交额持续萎缩。今日53.47亿，仅为20日均量78.54亿的68%（缩量32%），量比0.89，换手率0.14%创近期低位。9/15放量95.78亿 → 9/16的55.17亿 → 今日53.47亿，连续两日缩至9/15的约55%。资金参与度快速退潮，意味着即便有反弹也缺乏成交量支撑。

3）9/15的12.6亿抢筹已被证伪。9/15主力大举买入12.6亿、股价冲高446，本应是反转起点；但随后两天股价从438.80跌到426.00（累计-2.91%），那批12.6亿的资金目前处于浮亏状态。这意味着440~446区间已形成新的套牢盘，未来反弹到该区域会遭遇解套抛压。

怎么理解？回购是腾讯多年来最稳定的股价支撑力量之一，累计已投入201.79亿港元。8月股价在440~460时公司敢每天砸3亿，9月股价跌到425~440这个更便宜的位置，反而只买1亿——这与"越跌越买"的直觉相反。

可能的解释有两个：一是年度回购预算的节奏管理（前期用得多，需要为下半年留额度）；二是公司在等更低的价格。无论哪种，结果都是同一个：托底的买盘变薄了。这解释了为什么9月以来股价一跌就容易破位——过去每天3亿的"隐形买单"现在只有1亿。

值得跟踪的信号：若某天回购额重新放大回2~3亿，往往是公司认为价格已到位的表态，可作为重要的加仓参考信号。

为什么腾讯首当其冲？三条传导链：
1）折现率上升直接压制成长股估值。腾讯这类成长股的估值本质是"未来现金流的折现"。无风险利率上升25基点，分母变大，理论估值下移——越是依赖远期增长的资产，杀估值越狠。这正是恒生科技指数中权重股今天普跌的原因。
2）港元利率上升＝港股流动性收紧。联系汇率下香港被动跟随美国利率。港元融资成本上升，杠杆资金撤出，港股整体流动性变薄。今日恒指成交仅1515亿港元，腾讯成交额53.47亿（缩量32%），正是流动性收紧的直观体现。
3）外资偏好切换。加息环境下，资金从高波动的新兴市场权益类资产，回流美元现金与美债等无风险资产。港股作为离岸市场，对全球流动性变化最敏感。
