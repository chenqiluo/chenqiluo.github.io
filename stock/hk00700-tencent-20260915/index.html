今天是9月以来第一个「量价同时点头」的交易日，也是本轮反弹从「猜测」变成「确认」的分界点。过去三天最大的隐忧是量能连续腰斩（95.33亿 → 66.75亿 → 48.92亿），涨是涨了但没人接力；今天成交额73.73亿，环比放大50.7%，量比从0.65回到1.31，换手率从0.09%翻倍到0.18%——缺失的那一环补上了。日内过程：昨收430.60，今天低开428（低开0.60%），而428同时就是全天最低价，此后单边推到446，收439.40。
这根K线要读出五层信息。

第一层：连续第三根「开盘即最低」的光脚阳线，且三个价格连续三天全部抬高。最低价 419.4 → 423.8 → 428.0；最高价 430.8 → 435.4 → 446.0；收盘价 428.4 → 430.6 → 439.4。三天里每一天的开盘价都是当天最低点，意味着连续三个交易日、开盘之后就再没有卖方能把价格压回去。这不是随机波动，这是抛压持续枯竭、买盘持续占优的结构性特征。三天累计从9/10收盘425.6涨到439.4，+3.24%。

第二层：量能终于跟上了，这是最关键的变化。三天的量能路径是 95.33亿 → 66.75亿 → 48.92亿 → 73.73亿。9/14的48.92亿是近月地量，今天直接放大到73.73亿（+50.7%），并且是放量上涨而不是放量下跌。教科书里「地量见地价、量增价升」这两步，在9/14和9/15连着走完了。昨天报告里那句「修复动能已耗尽，而接力资金还没来」——今天资金来了。

第三层：今天是板块普涨，腾讯在大市值里领涨。同日网易+2.97%、腾讯+2.04%、阿里+1.32%、美团+0.13%、快手-2.09%。和昨天「腾讯独涨、其余全跌」的性质不同，今天有明显的板块贝塔（大摩的2C AI报告是共同催化剂）。要客观承认：今天的涨幅里有一部分是板块行情给的，不能全记在腾讯自己头上。但在4万亿体量下还能跑出2.04%、且资金数据是四家里最强的，含金量依然足。

第四层：需要泼冷水的地方——尾盘有获利回吐。全天最高446，收盘439.40，回落1.48%；今日均价439.638，收盘价比均价低0.24港元（-0.05%）。也就是说尾盘出现了小幅抛压，冲高446之后没能守住。446这个位置正好逼近MA20（441.31）上方，说明441~446这一带确实有实打实的卖单在等着。这是明天需要重点观察的：能否把446拿回来并站稳。

第五层：位置。439.40距52周高点677.70回撤35.16%，距52周低点411高出6.91%（三天前只有4.77%），年初至今仍跌25.99%。近5日转为+0.92%正收益，近60日+1.48%也已转正，只有近10日/20日仍小幅为负——短周期动能已经翻多，中周期正在修复。

换标尺就翻转的三个例子（提醒不要看单一排名）：① 论抗跌与分红，网易全面胜出（YTD -11.10%、股息2.44%）；② 论市净率便宜，阿里最低（PB 1.66×，因为重资产+大量云基础设施）；③ 论绝对估值便宜，快手PE仅7.14×最低，但它今天逆势跌2.09%、YTD跌52.67%，是典型的「便宜有便宜的原因」。

回到腾讯的定位结论（本章必须收敛回目标个股）：在这四家里，腾讯的位置是「基本面最稳、利润唯一正增长、估值第二便宜、体量最大」。
▪ 相对阿里：腾讯PE 14.75× vs 阿里25.27×，便宜42%；腾讯净利+15.82% vs 阿里-74.13%。买腾讯是买确定性，买阿里是买AI/云的弹性与转型期权。
▪ 相对美团：没有可比性——美团在亏损且被外卖价格战拖累，腾讯是净利率29.25%的现金牛。
▪ 相对网易：两者盈利质量最接近（净利率29.25% vs 29.68%），网易更抗跌、分红更高，但腾讯的成长空间与业务多元度显著占优（三大主业均衡 vs 网易单一游戏），且腾讯PE 14.75×还比网易15.98×便宜8%。

所以，投资腾讯本质上买的是什么？买的是「用14.75倍PE，买一家营收增15.6%、经营利润增20.1%、净利率29.25%、经营现金流是净利1.35倍、且AI是纯增量的社交流量垄断平台」。在整个中概板块普遍面临「增收不增利」（阿里、美团都是营收正增长但利润大跌）的当下，腾讯是唯一一家营收与利润双双双位数正增长的——这就是它在赛道里的核心稀缺性。
