今天是一根「低开、探底、单边回升、收在次高位」的缩量反弹阳线。日内过程：昨收35.74，今天低开于35.92（略高于昨收），开盘后先下探至35.64（小幅跌破昨收），随后稳步回升，最高触及37.22，尾盘略有回吐收36.66。全天振幅4.42%，明显小于9月21日的5.38%与9月18日的10.12%。成交额19.62亿港元，相比9月21日的33.10亿再缩量40.7%，量比仅0.83（低于1，意味着成交强度低于近五日平均）。收盘36.66高于全天均价36.407（高出0.253港元、0.70%）。
这根阳线要读出六层信息。

第一层：这波调整从头到尾都是缩量的，这是判断"休息"还是"反转"最核心的证据。三天的成交额序列非常清晰：9/18 = 55.62亿（暴涨日，放量）→ 9/21 = 33.10亿（调整日，缩量40.5%）→ 9/22 = 19.62亿（反弹日，再缩量40.7%）。成交额连续两天腰斩式萎缩，而价格只回调了一天就重新上行。这说明卖压在快速衰竭——想卖的人在9/21那天基本卖完了，之后就没量了。

第二层：但"缩量反弹"本身也是一个中性偏弱的信号，必须诚实指出。量比0.83低于1，意味着今天的买盘力度其实并不强。理想的反转形态是"缩量回调 + 放量反攻"，而今天是"缩量回调 + 缩量反弹"——价格回来了，但增量资金没有跟上。这意味着37.22~37.88这个前高区域还需要更大的成交量才能突破。

第三层：把三天连起来看，形成了一个漂亮的"缩量整理"结构。9/18最高37.88、9/21最低35.04、9/22最高37.22。三天的波动区间在35.04~37.88之间收窄，且逐日缩量——这是典型的"高位缩量横盘消化"，而不是"顶部放量派发"。技术上这种结构后续向上突破的概率通常大于向下破位。

第四层：位置依然很高，这一点没有改变。36.66距52周低点8.183高出347.9%，年初至今+310.85%，近60日+75.05%。距9月18日创下的历史新高37.88只差3.22%。这仍然是一只在历史最高区域运行的股票，与之前分析的壁仞（距高点-39.5%）、腾讯（距高点-32.4%）位置性质完全不同。

第五层：今天全球AI硬件同行涨跌互现，联想属中间偏强。同期可比标的：戴尔(DELL)+1.28%、浪潮信息+0.56%、工业富联-0.06%、惠普(HPQ)-4.22%。惠普大跌4.22%值得注意——它是五家里AI叙事最弱、纯PC属性最强的一家，这从侧面印证了当前市场买的是"AI服务器"而不是"PC"。联想+2.57%好于惠普与工业富联，弱于自己前几日的爆发力。

第六层：成交均价36.407与收盘36.66的关系是正向的。收盘高于均价0.70%，说明尾盘买盘略强于卖盘，当日买入者收盘时整体浮盈。这与9月21日"收盘低于均价2.5%"（按当时快照口径）的弱势结构相反，是情绪修复的直接体现。

所以逻辑链是：股价大涨 → 权证值钱了 → 会计上记一笔巨额亏损 → 报表显示亏6.09亿美元。这笔"亏损"一分钱现金都没有流出公司，也不代表任何经营恶化。剔掉它之后，主业真实赚了10.75亿美元、同比+176%、首次突破10亿美元。公司明确说明，该非现金会计项目预期到FY2027/28财年末仍将持续存在——只要股价继续涨，账面上就会继续"亏"。

一个反直觉的推论（本期特别值得注意）：本周股价从9/18的37.58回落到今天的36.66，净跌0.92港元。按这个逻辑，认股权证的公允价值会小幅回落，反而使下一期的账面"亏损"变小。在联想这只票上，"账面利润"与"股价"是负相关的——这正是必须弃用呈报PE的根本原因。

十一、政策面分析
正面：全球AI基建投资周期与国内政策共振
①全球AI资本开支仍在上行周期。超大规模云服务商、新型AI云与企业客户的AI基础设施投资持续加码，这是ISG订单储备一个季度从约210亿美元跳到540亿美元的宏观背景。公司预计2030年全球AI基础设施市场规模有望达1.3万亿美元。②央媒背书（上期新增，持续有效）：《新闻联播》聚焦联想集团，解码中国制造高端化转型——联想被定位为"中国制造高端化"的样本企业。③国内产能布局加码：与合肥的合作15年后再度加码。④本期新增：国标AI PC分级标准（L3）的推出本身就是政策层面的产业引导——国家出标准、联想成为唯一通过L3的厂商，这等于给联想的AI PC产品线加上了官方认证的护城河，对国内政企采购市场尤其有利。⑤中国"人工智能+"政策与算力基础设施建设持续推进，为联想中国区业务（占营收21.76%、本季+25%）提供政策托底。⑥国际认可：首次入选《时代》全球最佳企业榜单第51位；《财富》世界500强跃升43位至第153名创历史最高；Gartner全球供应链25强以第五名创历史最佳；作为2026年FIFA世界杯唯一官方技术合作伙伴为全部104场赛事提供AI技术。

政策面最大的不确定性有三条（与前期一致，未见缓解）。

第一，GPU供应受中美科技管制影响。联想的AI服务器业务本质是把英伟达等厂商的GPU集成到自己的机架方案里出售，这意味着增长上限被GPU可获得性直接锁定。公司披露中特意说明"剔除去年同期中国区销售国际GPU服务器收入影响后，国际市场AI服务器收入实现三位数同比增长"——这个措辞本身就反映了管制对中国区GPU服务器业务的实际影响。产品层面公司正推进GB300部署并加速Vera Rubin机架级解决方案商用准备，进展依赖供应链稳定。

第二，美国关税政策直接冲击占营收36.78%的美洲市场，而毛利率仅16.52%，几乎没有成本转嫁缓冲。联想的应对是"全球资源/本地交付"模式——已扩建美国北卡罗来纳州智能园区、新增服务器制造产能，全球11个市场布局30多个生产基地。这是有效对冲，但会推高成本。

第三，零部件供需失衡与成本上涨。公司在展望中明确提示"面对零部件供需持续失衡的挑战"。存储（内存/闪存）与HBM价格上行周期对PC与服务器厂商毛利率是直接压力——这一点在之前分析壁仞时也出现过（"国内HBM供应紧张、价格已大幅高于海外正常出货价"），说明这是整条AI硬件链的共同压力，不是联想独有。中金风险提示三条：AI资本开支不及预期、服务器竞争加剧、AI PC渗透率不及预期。

与前两只票的政策敞口对比：壁仞与腾讯几乎都是纯内需（壁仞"主要在国内市场开展业务"、腾讯收入几乎全部来自国内），不怕关税与出口管制；而联想78.24%的海外收入让它成为三者中政策敞口最大的一家。这在当前地缘环境下是实质性的折价因素。

核心判断：趋势是三只票里最确定的，位置是三只票里最危险的。看多不变，但今天这个价不追——昨天(9/21)是更好的介入点，今天已经不是。

看多的四条理由：
1. 整个回调过程都是缩量的，卖压在衰竭。成交额序列：9/18 = 55.62亿 → 9/21 = 33.10亿（缩量40.5%）→ 9/22 = 19.62亿（再缩量40.7%）。连续两天腰斩式萎缩，而价格只跌一天就重新上行——想卖的人基本在9/21卖完了。三天波动收窄在35.04~37.88，是标准的"高位缩量横盘消化"而非"顶部放量派发"。
2. 均线与方向指标是三只票里唯一"完美多头"的。七条均线全部多头排列且同步上行，MA5(35.62)已明确上穿MA10(33.74)并加速拉开距离；MACD红柱从0.580扩张到0.726（+25.2%）、DIF从1.715升到1.887；PDI(31.49)是MDI(15.75)的整整2.0倍；ADX从16.11升到21.39，趋势强度连续两天改善；SAR止损位从30.03上移到30.658。
3. 估值范式切换正在真实发生。今天惠普（纯PC、AI叙事最弱）大跌4.22%，而联想+2.57%、戴尔+1.28%——市场在用价格区分"卖PC的"与"卖AI服务器的"。这正是中金把目标价从30港元上修70%至51港元的核心逻辑（"P/E估值有望持续向行业中枢靠近"）。按经调整口径联想约13.8倍FY27E PE，仍是可比集最便宜之一，而增速最快。
4. 基本面与消息面持续加固。ISG收入+98%、经营利润率9.1%创历史新高、AI服务器订单储备540亿美元环比+157%已超戴尔的513亿、经调整净利10.75亿美元同比+176%；本期新增AI PC唯一通过L3级国标认证（利好占营收63.5%的IDG提质）、《AI原生组织转型指南》与具身智能产线首次公开（利好OPM 24.2%的SSG）；南向连续三日加仓、持股升至7.82%。
